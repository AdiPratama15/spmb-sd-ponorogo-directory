# SPMB Ponorogo SD - Daftar Sekolah

Website statis untuk menampilkan daftar sekolah SD SPMB Kabupaten Ponorogo.

## Fitur
- Pencarian data sekolah
- Sorting berdasarkan pagu
- Filter berdasarkan pagu
- Filter berdasarkan alamat
  - Kata pertama pada alamat dipakai sebagai kecamatan
  - Kata kedua setelah tanda koma dipakai sebagai desa/kelurahan

## Struktur Data
Data sekolah ditampilkan dalam tabel dengan kolom:
- Nama sekolah
- NPSN
- Tingkat
- Alamat
- Pagu

## Catatan
Website ini dibuat sebagai versi statis agar tetap dapat digunakan meskipun sumber data utama tidak dapat diakses.
